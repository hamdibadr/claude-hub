# Claude Hub

A local Claude Code project preloaded with Anthropic's official [skills](https://github.com/anthropics/skills), available under `.claude/skills/` for use with the `Skill` tool.

## Skills included

- academy-guide
- algorithmic-art
- brand-guidelines
- canvas-design
- claude-api
- discernment-nudge
- doc-coauthoring
- docx
- frontend-design
- internal-comms
- mcp-builder
- pdf
- pptx
- skill-creator
- slack-gif-creator
- theme-factory
- web-artifacts-builder
- webapp-testing
- xlsx

Each folder is a self-contained skill with its own `SKILL.md` and supporting files, cloned directly from [anthropics/skills](https://github.com/anthropics/skills).
